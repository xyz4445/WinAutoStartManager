# 使用说明

面向使用者。开发与内部实现见 [DEVELOPMENT.md](DEVELOPMENT.md)。

## 1. 安装与首次运行

程序是单文件绿色版，无需安装：

1. 把 `WinAutoStartManager.exe` 放到一个**固定位置**（例如 `D:\Tools\WinAutoStartManager\`）。放到临时目录或会被清理的下载文件夹，之后移动会导致自启动失效。
2. 双击运行。未做代码签名，首次可能被 SmartScreen 拦截：点「更多信息 → 仍要运行」。
3. 若提示无法创建窗口，说明缺少 WebView2 运行时，见 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)。

首次运行会在 `%LOCALAPPDATA%\AutoStartManager` 建默认数据目录。

## 2. 界面构成

![主界面](screenshot.jpg)

| 区域 | 说明 |
| --- | --- |
| 左上标题栏 | 产品名与一句话说明 |
| 右上「开机自启」开关 | 安装 / 移除两个计划任务；旁侧显示上次运行的成败统计 |
| 左侧「启动清单」 | 所有条目；绿点表示启用，黄标「管理员」表示提权运行 |
| 右侧编辑区 | 当前选中条目的所有字段 |
| 左下 | 「打开日志」「数据目录」快捷入口 |
| 右下 | 「设置…」「保存清单」 |

左侧条目卡片上会显示：「延迟 N 秒」「上次成功 / 上次失败」等摘要，不用点开就能看出哪一项上次没起来。

## 3. 条目字段

| 字段 | 说明 |
| --- | --- |
| **启用** | 关闭后条目保留在清单里，但登录时不启动 |
| **名称** | 清单中的显示名，可以是任意文本 |
| **程序路径** | 可执行文件完整路径。支持 `%LOCALAPPDATA%` 等环境变量。填完后下方会提示「已找到该程序」或标红 |
| **启动参数** | 可选，原样传给程序。例如 `mount G: remote: --vfs-cache-mode full` |
| **工作目录** | 留空则使用程序所在目录 |
| **延迟启动** | 秒数。**从用户登录开始计算的绝对时刻**，不是在前一个程序之后再等 |
| **权限层** | 「普通」= LeastPrivilege，「管理员」= HighestAvailable（静默提权） |

> 权限层选择要点：只有**确实需要**管理员令牌的程序才选「管理员」。普通程序选管理员会让它拿到不该有的权限，也会在多用户环境下更容易出问题。

## 4. 保存与关闭

- 修改**不会自动落盘**。点右下「保存清单」或按 `Ctrl+S` 才写入。
- 有未保存修改时关闭窗口会先确认；确认退出即放弃这些修改。
- 保存期间如果又产生新编辑，程序用修订号检测，不会错误清除「有未保存的更改」状态。

## 5. 开启开机自启

点右上角开关：

1. 勾选后程序会以管理员身份重新调用自身，通过 `schtasks` 写入两个计划任务。
2. 在启用了 UAC 的系统上会提示一次；UAC 已关闭的系统不提示。
3. 之后登录 Windows，清单中启用的条目按各自的延迟与权限层静默启动。

**之后修改清单不需要再动这个开关** —— 计划任务只保存 exe 路径，清单在登录时才读取。

### 开关状态说明

| 状态 | 含义 | 你该做什么 |
| --- | --- | --- |
| 已开启 · 登录时按清单启动 | 两个任务都已安装且指向当前 exe | 无需操作 |
| 未开启 · 登录时不会启动 | 尚未安装，或任务被删除 | 打开开关 |
| 需更新 · 任务指向旧路径 | exe 被移动或重命名 | 关闭再打开开关，让其指向新路径 |
| 状态未知 · 无法读取计划任务 | 任务查询失败，无法确认真实状态 | 开关保持原状；重开程序重试，或按 [TROUBLESHOOTING.md](TROUBLESHOOTING.md) 排查 |

「状态未知」是刻意设计：查询失败时**不会**把开关打回「未开启」，避免误判让你重复创建任务。

## 6. 测试运行

编辑区下方「测试运行」按钮会立刻按当前条目的设置启动一次（含权限层）。用于在不等待下次登录的情况下验证路径、参数、工作目录是否都正确。

测试运行同样遵循权限层：管理员条目会触发一次 UAC。

## 7. 设置

点右下「设置…」：

| 项 | 说明 |
| --- | --- |
| **数据目录** | 默认 `%LOCALAPPDATA%\AutoStartManager`，可改到任意文件夹。更改后程序自动重启；勾选「迁移」会把 `config.json`、`settings.json`、运行状态和日志复制到新目录，旧目录文件保留可手动删除 |
| **日志保留** | 默认 14 天，可设 1–365 天。程序启动时清理超期日志 |

数据目录位置记录在 `HKCU\Software\AutoStartManager\DataDir`，这样登录时启动的进程也能找到同一份清单。恢复默认目录时会自动清除该记录。

> WebView2 缓存不参与迁移，会在新目录自动重建。

## 8. 数据与日志

默认位于 `%LOCALAPPDATA%\AutoStartManager\`：

| 路径 | 内容 |
| --- | --- |
| `config.json` | 启动清单 |
| `settings.json` | 日志保留天数等设置 |
| `state-admin.json` / `state-user.json` | 各权限层最近一次运行结果 |
| `logs\launcher-<日期>-<层>.log` | 按天、按层记录；单文件超 2 MB 轮转为 `.1`，默认保留 14 天 |
| `webview2\` | WebView2 缓存，可安全删除 |

左下「打开日志」直接跳到日志目录。

## 9. 命令行参数

日常使用不需要，均由程序内部调用：

| 参数 | 说明 |
| --- | --- |
| 无参数 | 打开图形界面 |
| `--launch --tier=admin\|user` | 由计划任务调用，执行对应层的启动 |
| `--apply-tasks <结果文件>` | 提权后的自身进程调用，写入两个计划任务并把结果写入 JSON |
| `--apply-tasks <结果文件> --remove-tasks` | 提权后的自身进程调用，删除两个计划任务 |

## 10. 卸载

1. 先在界面中**关闭「开机自启」开关**（移除计划任务）。
2. 删除数据目录与注册表记录：

```powershell
Remove-Item -Recurse "$env:LOCALAPPDATA\AutoStartManager"
Remove-ItemProperty "HKCU:\Software\AutoStartManager" -Name DataDir -ErrorAction SilentlyContinue
```

3. 删除 exe。若改过数据目录，请同时删除自定义目录。

如果界面已无法打开，可手动清理任务：

```powershell
schtasks /Delete /TN AutoStartManager-Admin /F
schtasks /Delete /TN AutoStartManager-User /F
```
